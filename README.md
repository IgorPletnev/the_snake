## 🎮 Геймплей

Управляйте змейкой, собирайте яблоки и не врезайтесь в собственный хвост!

| Действие | Клавиша |
|----------|---------|
| ⬆ Вверх | `↑` |
| ⬇ Вниз | `↓` |
| ⬅ Влево | `←` |
| ➡ Вправо | `→` |

### Правила

- 🍎 **Съешь яблоко** — змейка вырастает на один сегмент
- 💥 **Столкновение с собой** — игра заканчивается, счёт сбрасывается
- 🔄 **Выход за границу** — змейка появляется с противоположной стороны

## 🚀 Быстрый старт

### 1. Клонируйте репозиторий

```bash
git clone <url-репозитория>
cd the_snake
```

### 2. Установите зависимости

```bash
pip install -r the_snake/requirements.txt
```

### 3. Запустите игру

```bash
python the_snake/the_snake.py
```

## 🧪 Тестирование

Проект покрыт **37 тестами**, которые проверяют:

- ✅ Наличие всех классов, методов и атрибутов
- ✅ Наследование (`Apple` → `GameObject`, `Snake` → `GameObject`)
- ✅ Типы глобальных переменных (`screen`, `clock`)
- ✅ Запуск игры без исключений

```bash
# Запуск всех тестов
cd the_snake
pytest tests/ -v
```

## ⚙️ Настройки

Все настройки вынесены в константы в начале файла [`the_snake.py`](the_snake/the_snake/the_snake.py:5):

| Константа | Значение | Описание |
|-----------|----------|----------|
| `SCREEN_WIDTH` | 640 | Ширина окна (пиксели) |
| `SCREEN_HEIGHT` | 480 | Высота окна (пиксели) |
| `GRID_SIZE` | 20 | Размер ячейки (пиксели) |
| `SPEED` | 17 | Скорость игры (FPS) |
| `BOARD_BACKGROUND_COLOR` | `(0, 0, 0)` | Цвет фона |
| `SNAKE_COLOR` | `(0, 0, 255)` | Цвет змейки |
| `APPLE_COLOR` | `(255, 0, 0)` | Цвет яблока |
